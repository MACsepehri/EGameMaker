# EGameMaker
EGameMaker is an open-source game engine based on python and pygame library for creating games easier and do most of works just with ui!

# Why EGameMaker
You're tired but you wanna create a game, here it is! This engine made for people who wanna create a small game very easy with most popular programming language, PYTHON!

# Usage
<b>Important :<br>Project hadn't completed and it's better to wait for '1.0.0' (stable release) version.</b>
```
git clone https://github.com/MACsepehri/EGameMaker
cd EGameMaker
python3 -m venv venv
source venv/bin/activate # in windows : ./venv/Scripts/activate
pip3 install Guide/requirements.txt
python3 EGameMaker.py
# enjoy it!
```
